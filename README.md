# poroject TH
## 설명
- 파이썬의 소켓 코드와 플러터의 실습을 위해 진행한 개인 프로젝트
- 파이썬이 컴퓨터에서 서버의 역할을 수행하고, 플러터로 모바일 프로그램을 만들어 통신 테스트
#### 구성
- Flutter 프론트엔드
- Python 백엔드
- VSCode
### 계획
#### 최종 목표
- 2~4인 접속을 지원하는 모바일 텍사스 홀덤
- 클라이언트 서버 구조로 메인 컴퓨터가 서버 역할을 하고 모바일에서 서버를 이용해 멀티 사용
	- 공유기 내부망 사용 예정
- 파이썬 소켓프로그래밍 공부가 핵심
#### 1차
- 파이썬으로서버 열기
- 플러터로 최소한의 ui 구성해 연결 테스트
#### 2차
- 카드 덱 만들어 배부, 표시 로직 만들기
- 체크 버튼 만들기
#### 3차
- 다중 인원이 접속 테스트
- 베팅기능 최소한의 도입
	- 통신 확인
#### 4차
- ui 마무리
- 베팅, 게임 종료 후 돈 분배, 버그 수정
